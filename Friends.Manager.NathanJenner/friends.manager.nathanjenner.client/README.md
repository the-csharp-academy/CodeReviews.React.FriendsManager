# Friends Manager client

React and TypeScript UI using Redux Toolkit and RTK Query for friendship and category state.
See the [project README](../README.md) for prerequisites, database setup, architecture, and development notes.

From this directory, run `npm ci`, then `npm run dev` with the HTTPS backend running.
Open https://localhost:5173. `/api` requests are proxied to https://localhost:7277.
Use `npm run build`, `npm run lint`, and `npm test` for validation.
